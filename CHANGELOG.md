# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
y este proyecto sigue [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-21

### Added
- MVP funcional del sistema de monitoreo
- Sistema de autenticación con JWT
- Tracking de tiempo en tiempo real
- Detección automática de inactividad
- Registro de actividades
- Reportes diarios, semanales y mensuales
- Dashboard ejecutivo
- Dashboard de empleado
- Análisis de eficiencia
- API REST completa con 20+ endpoints
- Documentación técnica completa
- Docker Compose setup
- GitHub Actions CI/CD
- Tests unitarios y de integración
- Logging y monitoreo

### Security
- Encriptación de contraseñas con bcrypt
- JWT tokens con refresh tokens
- Rate limiting implementado
- CORS configurado
- Validación completa de input
- Headers de seguridad

### Infrastructure
- PostgreSQL 15
- Redis para caché
- Nginx como proxy reverso
- Docker containers optimizados

## Versionado

Este proyecto usa [Semantic Versioning](https://semver.org/):
- **MAJOR**: cambios incompatibles en la API
- **MINOR**: nuevas funcionalidades compatibles hacia atrás
- **PATCH**: correcciones de bugs compatibles hacia atrás

## Cómo Reportar Cambios

1. Crea un PR con tus cambios
2. En el PR, describe qué se cambió
3. Usa Conventional Commits
4. Actualiza este archivo en la sección [Unreleased]
5. Espera aprobación y merge
